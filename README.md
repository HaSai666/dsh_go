# 黑白棋 · 3D 解压版

基于 three.js 的立体黑白棋(Reversi,**12×12 大棋盘,144 格**):每一步棋都有解压级音画反馈——棋子坠落拍击、多米诺式连锁翻面、棋盘震动、五声音阶翻面音效、大翻盘粒子爆裂、终局整盘翻色仪式。

**主页 + 两种模式**:

| 模式 | 玩法 |
| --- | --- |
| ⚫⚪ 经典模式 | 原汁原味的翻转棋,角最值钱 |
| 🃏 无尽卡牌 | **无尽闯关**(败北即止,连关无上限):开局拿满手牌,之后每回合抽 1 张;用行动力规划出牌顺序,棋盘随关卡从 12×12 增长到 18×18;过关后遗物/卡牌/手牌上限**三选一** |

**卡牌池(8 种)**:

| 卡牌 | 费用 | 效果 |
| --- | ---: | --- |
| ⚡ 连击 | 3 | 立即再落一子;额外回合不抽牌且只有 2 点行动力 |
| 💥 爆裂 | 2 | 落点周围一圈敌子全翻 |
| 🎲 天佑 | 2 | 随机 2 枚敌子归顺 |
| 🌱 播种 | 1 | 与你棋子相邻的空格长出己方棋子 |
| 🛡️ 护盾 | 2 | 对手下一次翻转无效 |
| 💣 爆破 | 2 | 随机炸飞 2 枚敌子(留空位) |
| 🔁 回响 | 1 | 重复本步上一张卡的效果(顺序敏感!) |
| 🧨 连锁 | 2 | 随机再翻 3 枚与己方相邻的敌子 |

**遗物(整局被动,4 种)**:

| 遗物 | 效果 |
| --- | --- |
| 👑 王冠 | 终局计分:你的角子每个额外 +2 |
| 🎩 手牌大师 | 手牌上限 +1 |
| 🧲 磁石 | 每次落子额外翻 1 枚相邻敌子 |
| 🍀 幸运草 | 每回合补牌时 30% 概率额外多补 1 张 |

**手牌与行动力规则**:

- 开局手牌补到上限,之后每回合只抽 1 张;未使用的牌保留,手牌满时不会继续抽牌
- 常规回合 3 点行动力;先手首回合 1 点,后手首回合 2 点
- 落后至少 12 子时获得"逆风 +1",该回合共 4 点行动力
- `连击`消耗 3 点并获得额外回合;额外回合不抽牌且行动力降为 2,不能形成无成本连锁
- 过关战利品可选"🀄 手牌上限 +1"(封顶 10)

战利品卡会加入后续关卡的固定起始手牌;数量超过手牌上限时优先保留最近获得的卡。已拥有的遗物不会重复出现,手牌满级后成长选项会替换为额外卡牌。

卡牌显示费用并有详细 tooltip;点击手牌按顺序排队(①②③),**顺序即触发顺序**;电脑会在同一行动力规则下搜索卡牌组合;悔棋连棋盘、手牌、行动轮次与护盾状态一起回滚。

## 运行

```bash
npm install
npm run dev    # → http://localhost:5173
npm test       # 纯逻辑回归测试
npm run test:balance # 固定种子先后手平衡模拟
npm run test:browser # 键盘/焦点/设置/动效偏好冒烟
npm run test:perf # 桌面/移动端 18×18 高密度盘面帧时间预算
npm run build  # 产物输出到 dist/
```

## 操作

- 主页选模式进入;游戏内右上角"主页"按钮返回
- 点击/触屏点击发光格子落子;悬停时幽灵棋子预览;卡牌模式先点手牌排队(顺序即触发顺序)再落子
- 拖拽/单指旋转视角、滚轮/双指缩放
- 快捷键:`R` 重开 / `U` 悔棋 / `M` 静音
- 键盘操作:Tab 聚焦棋盘,方向键切换合法落点,Enter/空格落子
- **移动端适配**:手机竖屏/横屏均可玩(棋盘自动构图,横屏体验更佳),触屏直接点格子落子

## 难度

- 经典三档:简单(贪心)、普通(α-β 3 层 + 机动性 + 前沿惩罚)、困难(迭代加深 900ms + 深度上限 10 + 空位 ≤10 时残局精确解)
- 无尽模式使用 24 子富开局随机二选一(绽放阵/网格阵),随关卡成长:
  - **棋盘**:12×12 起步,每关 +1,封顶 18×18
  - **敌方手牌上限**:第 3 关起每 2 关 +1(封顶 10)
  - **敌方开局加子**:第 3 关起 +2,每关 +1,封顶 +10
  - 🧲磁石:第 2 关起每步多翻 1 枚你的相邻子
  - AI 思考预算:600ms 起每关 +200ms,封顶 2000ms

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/game.js` | 黑白棋纯规则引擎 + 卡牌池与卡牌效果,无渲染依赖 |
| `src/run.js` | 无尽关卡成长、战利品与起始手牌规则,无渲染依赖 |
| `src/ai.js` | 三档落子 AI + 卡牌选牌策略 |
| `src/scene.js` | 3D 场景:绒布棋盘、实例化棋子/格子、软接触阴影、高亮、视差镜头与动画接口 |
| `src/fx.js` | 补间动画、棋盘震动、FOV 推冲、粒子爆裂 |
| `src/audio.js` | Web Audio 实时合成音效(落子/翻面/出牌/护盾/爆破),零素材 |
| `src/ui.js` | HUD、主页、卡牌手牌栏、终局弹窗 |
| `src/controller.js` | 对局流程、卡牌结算、护盾状态、悔棋回滚 |
| `src/main.js` | 入口与渲染循环(含 `window.__game` 等调试钩子) |

## 无头调试与像素级 QA

开发时用无头 Edge 自动试玩并做定量质检(`npm run qa`,需 dev 服务器在 5173 运行;该命令会先执行 `npm test`):

- `debug-headless.mjs` — 无头加载页面、采集控制台/网络错误,用真实鼠标事件走完:主页 → 经典模式全流程 → 返回主页 → 卡牌模式(手牌校验、UI 选牌出牌、护盾格挡断言),事件轨迹 + 定点抓拍(输出到 `debug-shots/`)
- `analyze-shots.mjs` — 对截图做像素级分析:整体亮度、棋盘色彩构成、黑白棋子对比度、合法格高亮、幽灵子、棋子投影、粒子爆裂、动画动态(坠拍/思考静止/电脑应手)与静态频闪检测
- `test-logic.mjs` — 规则引擎、卡牌效果与三档 AI 的纯逻辑自测
- `balance-smoke.mjs` — 96 局固定种子 AI 对弈,先手胜率需保持在 35%~65%
- `interaction-smoke.mjs` — 键盘棋盘、重复卡牌、模态焦点、设置记忆与减少动态效果回归
- `performance-smoke.mjs` — 桌面/移动端 12×12 与 18×18 高密度盘面的帧时间、draw call 与渲染比例预算

共 18 项像素/动态质检 + 逻辑自测 + 零运行错误,全部通过才算合格。

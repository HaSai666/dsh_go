# Third-party game assets

The bundled models are used in the 3D arena and are kept with their original license files.

- `kenney/cube-pets` — [Cube Pets](https://kenney.nl/assets/cube-pets), created by Kenney, CC0.
- `kenney/mini-arena` — [Mini Arena](https://kenney.nl/assets/mini-arena), created by Kenney, CC0.

The source packages provide GLB models and are suitable for personal and commercial projects under CC0. The local `License.txt` files are retained with the extracted assets.
